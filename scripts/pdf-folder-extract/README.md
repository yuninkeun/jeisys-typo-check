# PDF 폴더 일괄 텍스트 추출기 (로컬 실행용 폴더)

배포된 검증 사이트는 서버(Vercel)가 여러분 PC의 폴더에 접근할 수 없어서, "폴더 지정 → 일괄 처리"는 각자 PC에서 실행하는 별도 프로그램으로 만들었습니다. 이 프로그램은 PDF에서 텍스트만 추출해 CSV로 저장합니다(오탈자 검사는 하지 않음). 오탈자 검사는 사이트의 파일 업로드 기능을 그대로 이용해 주세요.

예전엔 node.exe에 코드를 심어서 단일 .exe로 만들었는데, 그 방식은 일부 PC의 백신/보안 프로그램이 "변조된 실행 파일"로 오탐해서 실행이 막혔습니다. 지금은 **원본 node.exe를 그대로** 쓰고, 우리 코드는 평범한 텍스트 파일로 두는 방식이라 오탐 가능성이 훨씬 낮습니다.

## 사용 방법 (받는 사람)

1. 이 폴더(`node.exe`, `run.bat`, `extract-bundle.cjs`, `pdf.worker.mjs` 4개 파일) 전체를 **같은 폴더에** 받으세요.
2. 검사하고 싶은 PDF가 들어있는 폴더를 `run.bat` 위로 끌어다 놓으세요.
   - 또는 `run.bat`을 더블클릭해서 실행한 뒤, 열리는 창에 폴더 경로를 붙여넣고 Enter.
3. 하위 폴더까지 모든 PDF를 찾아 텍스트를 추출하고, 같은 폴더 안에 `pdf-text-extract_<시간>.csv` 파일을 만듭니다.
4. 인터넷 연결, 로그인 모두 필요 없습니다. 추출한 내용은 그 PC를 벗어나지 않습니다.

그래도 실행이 막히면, `run.bat`을 더블클릭하지 말고 `cmd` 창을 연 뒤 그 폴더로 이동해서 `run.bat`을 직접 입력해 실행해 보세요 — 창이 바로 꺼지지 않고 에러 메시지가 남습니다.

## 한계: 인쇄용 아웃라인 PDF는 텍스트가 비어서 나옵니다

인쇄소에 보내는 라벨/스티커 일러스트 PDF는 보통 글자를 "아웃라인"(윤곽선 도형)으로 변환해서 저장합니다. 이 도구는 PDF 안의 실제 글자 데이터만 읽기 때문에, 아웃라인 처리된 파일은 CSV의 텍스트 칸이 빈 채로 나옵니다 — 에러는 아니고, 그냥 뽑아낼 글자 데이터 자체가 없는 겁니다.

이런 파일의 오탈자를 확인하려면 사이트의 단일 파일 업로드(`/check`)를 쓰세요. 그건 OpenAI 비전 모델로 파일을 이미지처럼 읽기 때문에 아웃라인이어도 인식합니다.

## 다시 빌드하기 (개발자용)

`extract-source.cjs`를 고친 뒤:

```
node scripts/pdf-folder-extract/build.cjs
```

Node 20+ 가 설치된 PC에서 실행하세요. `node.exe`(그 PC의 원본 Node 실행 파일 복사본), `run.bat`, `extract-bundle.cjs`가 다시 만들어집니다. `pdf.worker.mjs`는 `node_modules/pdf-parse`가 바뀌지 않는 한 다시 복사할 필요 없습니다.
